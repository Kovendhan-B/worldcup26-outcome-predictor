# FIFA World Cup 2026 Match Predictor

## Overview

A machine learning application that predicts the outcome of international football matches using historical FIFA match data.

## Features

- Historical Team Statistics
- Recent Form Analysis
- Head-to-Head Records
- Elo Rating System
- Tournament Context Features
- CatBoost Classification Model

## Tech Stack

- Python
- Pandas
- Scikit-Learn
- CatBoost
- Streamlit

## Results

| Model | Accuracy |
|---------|---------|
| Random Forest | 59.28% |
| CatBoost | 59.44% |
| CatBoost + Elo | 56.55% |
